## Definition

The Client's share of a Marketplace sale: a default percentage with an optional override per listing, applied to each sale.

## Distinguish From

Not the Payment Provider's own fees, which are separate ongoing costs.

## Usage

Configured in the administration panel; deducted when the payment is released.
