## Definition

A price proposed by a signed-in buyer for a coin on which Make an Offer is enabled. It is rejected automatically if below the minimum acceptable offer; otherwise the seller (for Royal Aurum's own coins, the Client) accepts or declines it.

## Distinguish From

Not a bid: offers are never shown publicly and do not compete. Not a counter-offer, which does not exist.

## Usage

Make an Offer on Royal Aurum's own coins and on Marketplace listings.
