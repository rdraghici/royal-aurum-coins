## Definition

The private threshold set for a coin by its seller, or by the Client for Royal Aurum's own coins; an offer below it is rejected automatically without the threshold being revealed.

## Distinguish From

Not the listed price, and never shown to buyers. The administrator can see it.

## Usage

Set per coin when Make an Offer is enabled.
